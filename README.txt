AVIS Việt Nam - bản HTML tĩnh

Mở index.html trực tiếp bằng trình duyệt. Không cần cài đặt hoặc chạy máy chủ.
Giữ nguyên thư mục assets, styles.css và script.js cạnh các file HTML.

Các trang được liên kết bằng đường dẫn tương đối. Menu, trình chiếu, tìm kiếm
và kiểm tra biểu mẫu liên hệ hoạt động trong trình duyệt. Biểu mẫu chỉ kiểm tra
dữ liệu tại chỗ; không gửi thông tin tới máy chủ.

Muốn xuất lại sau khi sửa nội dung Angular: chạy npm run export:static.
