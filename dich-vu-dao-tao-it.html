NĂNG LỰC CHUYÊN MÔN

Các chương trình đào tạo trọng điểm

Giáo trình được cập nhật định kỳ theo xu hướng công nghệ mới nhất trên thị trường quốc tế.

BE

Backend Engineering

Java Spring Boot, .NET Core, Node.js, kiến trúc RESTful API, tối ưu CSDL SQL/NoSQL và bảo mật hệ thống.

FE

Modern Frontend

TypeScript, Angular, React, Vue, State Management, tối ưu Web Vitals và thiết kế giao diện đáp ứng đa thiết bị.

QA

Software QA & Testing

Quy trình kiểm thử chất lượng, thiết kế Test Case, API Testing, Automation Testing (Selenium, Playwright) và CI/CD.

DO

Cloud & DevOps

Quản trị Linux, Docker Container, Kubernetes Orchestration, CI/CD Pipeline (GitHub Actions, GitLab) và AWS Cloud.

BA

Business Analysis

Kỹ năng khơi gợi yêu cầu, mô hình hóa quy trình BPMN, viết User Stories và xây dựng tài liệu đặc tả kỹ thuật BRD/SRS.

DB

Data Analytics & SQL

Thiết kế cơ sở dữ liệu quan hệ, tối ưu câu lệnh truy vấn phức tạp, xây dựng Data Pipeline và trực quan hóa Dashboard.

01 / FORMAT

Hình thức đào tạo linh hoạt

Thiết kế phù hợp cho cả học viên cá nhân, đội nhóm nội bộ và đào tạo doanh nghiệp (In-house Training):

  • ⚡ Khóa nền tảng dành cho kỹ sư chuyển đổi chuyên môn
  • ⚡ Khóa chuyên sâu nâng cao theo từng công nghệ chuyên biệt
  • ⚡ Đào tạo theo hợp đồng may đo riêng cho doanh nghiệp
  • ⚡ Mô hình Mentoring 1-1 hỗ trợ giải quyết bài toán thực tế
02 / OUTCOMES

Cam kết chất lượng đầu ra

Đánh giá năng lực dựa trên chất lượng mã nguồn thực tế và đồ án tốt nghiệp:

  • ⚡ Đồ án tốt nghiệp đạt chuẩn Production-ready
  • ⚡ Code Review trực tiếp 1-1 cùng Tech Lead
  • ⚡ Đánh giá năng lực định kỳ theo khung chuẩn quốc tế
  • ⚡ Hỗ trợ kết nối cơ hội việc làm tại AVIS và các đối tác
